# M2 FP16 NER 阶段结果

日期：2026-10-04

## 运行环境

- Apple M2
- 16GB 内存
- macOS 14.8.1 (23J30)
- Python 3.13 隔离环境
- MLX 0.32.3 / MLX-LM 0.32.0
- HaS Text 0.6B FP16 safetensors

## 性能结果

使用官方 NER prompt 和 chat template，合成文本连续运行 10 次：

| 指标 | 结果 |
|---|---:|
| 成功运行 | 10/10 |
| 单次延迟 | 0.818–0.856 秒 |
| 生成速度 | 67.2–68.6 tokens/s |
| 模型报告峰值内存 | 约 1.32GB |
| Python 进程峰值 RSS | 约 1.55GB |
| Metal/MLX | MLX Apple Silicon 后端正常工作 |
| 崩溃/明显变慢 | 未发现 |

## 输出可靠性

合成文本包含姓名、机构、电话、案号 4 个实体。10 次结果均：

- 返回可解析 JSON；
- 实体类型合法；
- 实体值存在于原文；
- offset 校验通过；
- 无幻觉实体；
- 无重复或跨边界实体；
- exact match 为 4/4。

直接使用 raw completion prompt 会导致模型续写原文；必须使用 Qwen chat template。这个调用约束必须固化在产品代码中。

## 三方案合成样本对比

样本数 3，标注实体数 11：

| 方案 | TP | FP | FN | Precision | Recall | F1 |
|---|---:|---:|---:|---:|---:|---:|
| 规则 | 4 | 0 | 7 | 1.000 | 0.364 | 0.533 |
| FP16 NER | 9 | 1 | 2 | 0.900 | 0.818 | 0.857 |
| 规则 + FP16 NER | 10 | 0 | 1 | 1.000 | 0.909 | 0.952 |

这只是合成样本结果，不能代表真实法律材料效果。

## 阶段结论

FP16 HaS 在当前 M2/16GB 上满足本阶段运行验收：内存和稳定性可接受，语义实体识别明显优于规则，规则+NER 组合效果最佳。它可以进入真实材料抽样评估，但还不能直接进入桌面安装包或自动脱敏流程。
