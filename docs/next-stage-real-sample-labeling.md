# 下一阶段：真实材料抽样标注与人工复核

## 阶段目标

验证合成样本结论能否迁移到律师实际使用的中文合同、裁判文书、委托材料和聊天记录。

## 执行范围

从外部测试材料中选择 8–12 份代表性文件：

- 3 份有文本层 PDF；
- 2 份 DOCX；
- 2 份纯文本/邮件；
- 1–5 份图片或扫描 PDF 仅作为后续 OCR 预研样本。

原始文件继续留在外部资产目录，不复制进项目，也不上传模型服务。

## 标注方法

1. 先从文件中抽取文本到本地临时目录；
2. 人工标注八类实体：姓名、组织、手机号、身份证号、银行卡号、地址、案号、合同编号；
3. 每个实体记录 `type/value/start/end`；
4. 用脚本校验每个 span 是否与原文完全一致；
5. 标注完成后删除临时原文，只保留必要的本地评估文件；
6. 对低置信度或存在争议的实体保留人工备注。

## 对比指标

重复上一阶段三方案：规则、FP16 NER、规则+FP16 NER。新增：

- 每页/每千字延迟；
- 人工修改和忽略次数；
- 误报类型；
- NER 输出 JSON 失败率；
- 同一实体跨段落一致性；
- 律师可接受的复核时间。

## 验收标准

- 真实样本至少 100 个标注实体；
- 规则+NER 的总体 F1 和各核心类别结果可复现；
- 任何自动脱敏前必须经过人工确认；
- 统计误报是否会改变法律事实、主体关系、金额或日期；
- 决定 FP16 是否继续作为默认模型，或仅在增强模式提供 Q8/FP16。

## 本阶段不做

- 不做 Tauri 安装包；
- 不做自动覆盖原始文件；
- 不接真实云端模型；
- 不引入更大模型；
- 不把未标注真实材料作为“准确率”依据。
