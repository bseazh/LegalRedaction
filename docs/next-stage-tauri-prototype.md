# 下一阶段：Tauri 本地桌面原型

真实材料评估已完成：10 份文件、42 个 gold 实体，规则/FP16 NER/混合方案结果已保存。下一阶段开始做 macOS Apple Silicon 的本地桌面原型。

## 目标

把当前已经验证的本地服务包装成一个可下载安装的最小桌面应用：

```text
拖入 DOCX/PDF/TXT
  -> 本地解析
  -> 规则 + MLX FP16 NER
  -> 候选高亮
  -> 人工确认/忽略/修改
  -> Token 化
  -> 导出脱敏文本
```

## 第一版只做

- macOS Apple Silicon；
- TXT、DOCX、有文本层 PDF；
- 规则 + FP16 NER；
- 候选审查；
- 本地 Tokenization；
- 导出 `.txt` 和 JSON 映射；
- 映射表只保存在本机，并加密或至少隔离存储。

## 第一版不做

- OCR/扫描 PDF；
- 图片视觉检测；
- 云端模型调用；
- 系统级代理；
- Windows 打包；
- 自动接受所有模型结果；
- 覆盖原始文件。

## 技术结构

- Tauri：窗口、拖拽、文件选择、结果展示和导出；
- Python sidecar：复用 `service/redaction_core.py`、`service/mlx_ner.py`；
- MLX 环境：先作为开发运行时，之后再评估如何随应用分发；
- 模型：FP16 已验证可在 M2/16GB 运行，但是否内置安装包仍需做安装体积和签名测试。

## 验收标准

- 原始文件不被修改；
- 识别和脱敏全程本地完成；
- 模型候选必须人工确认后才能导出；
- 导出结果可重新打开和校验；
- 应用关闭后本地服务能正确退出；
- 首次启动和连续处理不明显拖垮系统；
- 记录模型、规则和处理时间，但不把原文写入普通日志。
